## 🚀 Featured Projects

### 🤖 [AIstotle](https://github.com/Jchute96/AIstotle)
A transformer LLM built from scratch in PyTorch, trained on philosophy texts.
- Built a custom BPE tokenizer using a doubly linked list which led to a **1,700x speedup** over my original approach
- Implemented multi-head attention, residual connections, and layer normalization from scratch
- Designed a data pipeline that collects and cleans multiple texts from Project Gutenberg
- Trained model using cross-entropy loss and Adam optimizer on curated dataset

### 📚 [BookShelf](https://github.com/Jchute96/bookshelf) · [Live Demo](https://web-production-6dbf7.up.railway.app/demo-login)
Full-stack Django web app for tracking your reading that is deployed on Railway with PostgreSQL.
- AI-powered book recommendations using Claude API with Google Books API cover enrichment
- 67 automated tests with CI/CD via GitHub Actions on every push
- CSV and PDF export, statistics dashboard, and advanced search/filtering
